# src/components/ui/

## Purpose

This folder contains **base UI building block components** — the smallest reusable pieces of the interface.

## File Types

- `.tsx` files — React components (e.g., `button.tsx`, `input.tsx`, `card.tsx`, `modal.tsx`)

## Rules

1. Each component should be **self-contained** and reusable across the entire app.
2. Components here should have no business logic — they are purely presentational.
3. Use Tailwind CSS for styling.
4. Accept props for customization (variants, sizes, colors, etc.).
5. Examples of what belongs here: Button, Input, Select, Checkbox, Card, Badge, Avatar, Tooltip, Dialog, Dropdown.
